# Task_Manager
a TODO list for projects and daily tasks to complete

## Final Result Plan

### Static Elements
* Side navigation bar
    * swap through different views/menus
* top header bar
    * shows day of week & date
    clickable "Task Manager" Button
        * returns to Dashboard view/menu

### Dashboard
* landing page and overall summary of things to do
    * tile showing todays workout
    * tile showing favorite project (or empty if no favorite project)
    * tile with progress circle of dailies completed (% and x/x completed)

### Projects
* tiled grid of projects being worked on
* name, small icon, short description, star
    * star is to mark as favorite or priority
    * only 1 project can be marked as favorite at a time
    * marking favorite unmarks others
* tiles can be clicked on to open list of tasks to do
    * either popup window or full new view
    * tasks can be added / removed / marked as complete
    * tasks don't show up on tasks page

### Tasks
* random tasks that need to be done
* not part of a project
* ex: get passport / do taxes

### Dailies
* simple task list
* list of daily things to do, ex: get dressed / shower
* can be marked complete
* resets completion daily

### Workout
* Tile grid
* Sunday-Saturday
* bullet list boxes(editable) of workout plan
    * title bar for day
    * can be clicked on to grey out (mark as complete)
* resets grey out/completion weekly
